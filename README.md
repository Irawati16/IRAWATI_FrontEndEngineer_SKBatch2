# TalentHub – Penjelajah Lowongan Pekerjaan

TalentHub adalah website sederhana yang dirancang untuk membantu pengguna menemukan peluang karier berdasarkan departemen pekerjaan. Project ini dibuat sebagai bagian dari Mini Assignment Front-End Engineer.

**Live Demo:** [TalentHub – GitHub Pages](https://irawati16.github.io/IRAWATI_FrontEndEngineer_SKBatch2/)

## Fitur Utama

- **Responsive Design** – Tampilan menyesuaikan ukuran layar desktop, tablet, dan mobile.
- **Department Filter** – Pengguna dapat memfilter lowongan berdasarkan departemen.
- **Dynamic Job Listing** – Daftar pekerjaan ditampilkan secara dinamis menggunakan JavaScript.
- **Empty State** – Menampilkan informasi ketika departemen yang dipilih belum memiliki lowongan.
- **Responsive Navigation** – Navbar menyediakan navigasi desktop dan menu hamburger untuk perangkat mobile.
- **Horizontal Scrolling Filter** – Filter departemen dapat digulir secara horizontal pada berbagai ukuran layar.
- **Active Navigation** – Menu navigasi memberikan indikator warna pada menu yang sedang dipilih.

## Cara Menjalankan Project

1. Clone repository:
   ```
   git clone https://github.com/irawati16/IRAWATI_FrontEndEngineer_SKBatch2.git
   ```
2. Masuk ke folder project:
   ```
   cd IRAWATI_FrontEndEngineer_SKBatch2
   ```
3. Buka folder project menggunakan Visual Studio Code.
4. Jalankan file `index.html` menggunakan ekstensi **Live Server**.
5. Website TalentHub akan terbuka melalui browser.

## Cara Menggunakan

1. Buka halaman utama TalentHub.
2. Pilih departemen yang ingin dijelajahi.
3. Website akan menampilkan lowongan pekerjaan sesuai departemen yang dipilih.
4. Jika belum tersedia lowongan, website akan menampilkan Empty State.
5. Klik **Lihat Semua Lowongan** untuk kembali menampilkan seluruh pekerjaan.
